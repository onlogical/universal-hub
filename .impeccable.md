## Design Context

### Users
Universal Hub is used by Roblox players running game-specific automation during active play. They need fast, glanceable control and status feedback without losing sight of the game or interrupting time-sensitive actions.

### Brand Personality
Familiar, refined, and confident. The Hub should feel like one coherent native tool: compact, direct, and polished rather than flashy or ornamental.

### Aesthetic Direction
Use Universal Hub's existing charcoal surfaces, warm coral primary accent, restrained borders, Builder Sans typography, compact radii, and established spacing. Favor dark, information-dense floating surfaces with clear hierarchy and progressive disclosure. Avoid oversized cards, generic dashboards, neon/glowing treatments, glassmorphism, and decorative UI that competes with gameplay.

### Design Principles
1. Keep gameplay visible: overlays stay compact, positionable, and easy to dismiss or collapse.
2. Make automation legible: always show the current stage and the next meaningful action.
3. Use progressive disclosure: summarize first, expose detailed egg/server data on demand.
4. Reuse Hub tokens and interaction patterns so every game adapter feels familiar.
5. Animate only to explain entry, exit, stage changes, and newly discovered targets.
